### Inventory

Take an inventory of the sites by using the Ansible inventory. Run a dynamic inventory script to get the list of hosts and their details.

```bash
ansible-inventory -i inventory/hawkfield.proxmox.yml --list
```

```bash
ansible-inventory -i inventory/london.proxmox.yml --list
```
